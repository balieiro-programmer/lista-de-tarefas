# 📝 Lista de Tarefas

Aplicação web desenvolvida para ajudar na organização de atividades do dia a dia, permitindo adicionar, concluir, desfazer e excluir tarefas de maneira simples e intuitiva.

## 🚀 Demonstração

[Acessar aplicação](https://balieiro-programmer.github.io/lista-de-tarefas/)

## ✨ Funcionalidades

- Adicionar novas tarefas.
- Marcar tarefas como concluídas.
- Desfazer a conclusão de uma tarefa.
- Excluir tarefas individualmente.
- Remover todas as tarefas concluídas de uma vez.
- Contabilizar tarefas totais e concluídas.
- Salvar tarefas automaticamente no navegador utilizando LocalStorage.
- Interface responsiva para diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 💻 Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de praticar e aprimorar conhecimentos em desenvolvimento web, especialmente na manipulação do DOM, eventos JavaScript, armazenamento local e organização de interfaces.
